# Simulação de Rede de Roteadores em C

## Descrição

Este projeto foi desenvolvido em linguagem C com o objetivo de simular o funcionamento de uma rede de roteadores utilizando matriz de adjacência.

O sistema permite analisar conexões entre roteadores e validar caminhos dentro da rede.

---

## Funcionalidades

* Análise de conexões entre roteadores
* Identificação de entradas e saídas
* Verificação de conexões bidirecionais (full duplex)
* Detecção de roteadores isolados
* Identificação do roteador com maior número de conexões
* Validação de caminhos na rede

---

## Tecnologias utilizadas

* Linguagem C
* Lógica de programação
* Estruturas condicionais e de repetição
* Manipulação de arrays

---

## Como executar

1. Compile o código:

```
gcc projeto.c -o programa
```

2. Execute:

```
./programa
```
